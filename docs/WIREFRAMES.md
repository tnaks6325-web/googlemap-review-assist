# 화면 와이어프레임 (텍스트)

> 관련: [USER_FLOWS.md](USER_FLOWS.md) · [API_SPEC.md](API_SPEC.md)
> 표기: 모바일(고객)은 360×640 기준, 데스크톱(사장님)은 와이드. `[버튼]`, `( )`라디오, `[x]`체크, `____`입력.

---

## 고객(리뷰어) — 모바일 웹

### 화면 흐름 맵
```
R0 진입 → R1 OTP → R2 영수증 → R3a 별점 → R3b 메뉴 → R3c 소감
   → R4 적립완료 → (선택) R5 초안 → (선택) R6 게시안내 → R7 적립금
```

### R0. 캠페인 진입 (`/r/{slug}`)
```
┌─────────────────────────────┐
│        [매장 로고/상호]       │
│   "리뷰 남기고 적립받기"       │
│                             │
│  방문해 주셔서 감사합니다 🙏    │
│  영수증 인증 후 간단 설문이면    │
│  적립이 완료돼요 (1분 소요)     │
│                             │
│        [ 시작하기 ]          │
└─────────────────────────────┘
⚠ active=false → "지금은 참여할 수 없어요" 안내만
```

### R1. 휴대폰 OTP
```
단계 1               단계 2
┌───────────────┐   ┌───────────────┐
│ 휴대폰 번호      │   │ 인증번호 입력    │
│ [010________]  │   │ [ _ _ _ _ _ _ ]│
│                │   │ 02:59 남음      │
│ [ 인증번호 받기 ]│   │ [재발송](비활성) │
│                │   │ [ 확인 ]        │
└───────────────┘   └───────────────┘
→ POST /api/auth/otp/request → /verify
⚠ 60s 재발송 제한, 5회 실패 잠금
```

### R2. 영수증 인증
```
┌─────────────────────────────┐
│  영수증 인증                  │
│  ─────────────────          │
│  영수증의 승인번호를 입력하세요   │
│  [ ____________________ ]   │
│                             │
│  (P1) 또는 [ 영수증 사진 촬영 ] │
│                             │
│        [ 확인 ]              │
└─────────────────────────────┘
→ POST /api/receipts
⚠ 중복=「이미 참여한 영수증」 / 매칭실패=재입력
```

### R3a. 별점
```
┌─────────────────────────────┐
│  오늘 방문은 어떠셨나요?         │
│                             │
│     ★  ★  ★  ★  ☆          │  ← 탭으로 선택
│        (4점 선택됨)           │
│                             │
│              [ 다음 ]        │
└─────────────────────────────┘
```

### R3b. 좋았던 메뉴 (멀티선택 칩)
```
┌─────────────────────────────┐
│  무엇이 좋았나요? (복수 선택)    │
│                             │
│  [x]김치찌개  [ ]제육볶음      │
│  [x]계란말이  [ ]된장국        │
│  [ ]공기밥                   │
│                             │
│              [ 다음 ]        │
└─────────────────────────────┘
(메뉴는 GET /api/campaigns/{slug}의 menus)
```

### R3c. 한 줄 소감 + 제출 (적립 확정 지점)
```
┌─────────────────────────────┐
│  한마디 남겨주세요 (선택)        │
│  [ 반찬이 깔끔하고 양이 많아요  ]│
│  [ 🎤 음성으로 입력 ]          │
│                             │
│   제출하면 적립금이 지급돼요      │
│        [ 제출하고 적립받기 ]    │
└─────────────────────────────┘
→ POST /api/feedback  (설문 저장 + EARN, 단일 트랜잭션)
※ 이 버튼이 보상 트리거. 게시와 무관 (C1)
```

### R4. 적립 완료
```
┌─────────────────────────────┐
│            ✅               │
│      +500P 적립 완료!         │
│      현재 잔액 2,500P         │
│  ─────────────────          │
│  원하시면 방금 남긴 내용을       │
│  리뷰 초안으로 만들어 드려요      │
│                             │
│   [ 리뷰 초안 받기 (선택) ]    │
│   [ 그냥 마치기 ]             │
└─────────────────────────────┘
※ '그냥 마치기'를 눌러도 적립 유지 (C3)
```

### R5. AI 초안 (선택)
```
┌─────────────────────────────┐
│  리뷰 초안 (직접 수정 가능)      │
│  ┌─────────────────────────┐ │
│  │ 김치찌개랑 계란말이를 먹었는 │ │
│  │ 데 반찬이 깔끔하고 양도 많아 │ │
│  │ 만족스러웠어요. ...         │ │
│  └─────────────────────────┘ │
│  [ 다시 생성 ]  [ 복사하기 ]   │
└─────────────────────────────┘
→ POST /api/drafts (실패해도 적립 영향 없음)
```

### R6. 게시 안내 (선택, 자율)
```
┌─────────────────────────────┐
│  초안이 복사되었어요 📋         │
│                             │
│  구글맵에서 붙여넣기 하면 끝!    │
│  (작성·수정·게시는 자유예요)     │
│                             │
│   [ 구글맵에서 리뷰 쓰기 → ]   │  ← 외부 딥링크만
└─────────────────────────────┘
※ 게시 대행/자동게시 없음 (C3)
```

### R7. 적립금 지갑
```
┌─────────────────────────────┐
│  내 적립금        2,500P       │
│  ─────────────────          │
│  +500P  ○○식당 설문    6/29   │
│  +500P  △△카페 설문    6/20   │
│  -1000P 정산출금       6/10   │
│                             │
│   [ 정산 요청 ] (P1)          │
└─────────────────────────────┘
→ GET /api/points/balance, /transactions
```

## 사장님(Owner) — 데스크톱 웹

### O1. 매장 등록
```
┌──────────────────────────────────────────┐
│ 매장 등록                                   │
│ 상호      [________________]               │
│ 주소      [________________]               │
│ 구글 Place[ 검색: 상호 입력 → 후보 선택 ]    │
│                              [ 저장 ]      │
└──────────────────────────────────────────┘
```

### O2. 메뉴 관리
```
┌──────────────────────────────────────────┐
│ 메뉴 관리                          [+ 추가] │
│ ┌──────────────┬───────────┬───────────┐  │
│ │ 이름          │ 카테고리   │           │  │
│ │ 김치찌개       │ 식사       │ [수정][삭제]│ │
│ │ 계란말이       │ 사이드     │ [수정][삭제]│ │
│ └──────────────┴───────────┴───────────┘  │
└──────────────────────────────────────────┘
```

### O3. 캠페인 / QR 발급
```
┌──────────────────────────────────────────┐
│ 리뷰 요청 채널                              │
│ 캠페인명 [____________]  [ 발급 ]           │
│ ──────────────                            │
│  ▦ QR        링크: short.ly/abcd          │
│ [QR 이미지]  [QR 다운로드] [링크 복사]       │
└──────────────────────────────────────────┘
→ POST /api/business/{id}/campaigns
```

### O4. 대시보드
```
┌──────────────────────────────────────────┐
│ 대시보드                      [기간: 30일 ▾]│
│ ┌─────────┐ ┌─────────┐ ┌──────────────┐ │
│ │ 피드백   │ │ 평균별점 │ │ 게시 전환율(참고)│ │
│ │  128건   │ │  4.3★   │ │   34% (P1)    │ │
│ └─────────┘ └─────────┘ └──────────────┘ │
│ ── 별점 추이 ──────────────  (라인 차트)    │
│ ── 인기 메뉴 TOP ─────────   (바 차트)      │
│ ── 불만 키워드 ──────────    (태그 클라우드) │
└──────────────────────────────────────────┘
→ GET /api/business/{id}/stats
```

## 공통 UI 원칙

- 고객 플로우는 **한 화면 = 한 결정**. 진행바(1/6 …)로 짧음을 인지시킴.
- 적립은 R3c 제출 즉시 확정 → R4에서 명확히 피드백. "게시해야 적립"이라는 오해 문구 금지 (C1/C3).
- 게시 관련 화면(R6)은 항상 **외부 이동 + 자율** 톤. 강제/대행 뉘앙스 배제.
- 오류 화면은 재시도 경로를 항상 제공(영수증 매칭 실패, OTP 실패, 초안 실패).
