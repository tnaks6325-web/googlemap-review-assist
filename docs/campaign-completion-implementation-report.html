API / 데이터 변경

캡처 제출 API

POST /api/reviewer/campaigns/complete Request: multipart/form-data - assignmentId: receipt_id - draftText: 생성된 리뷰 원고 - screenshot: JPG/PNG/WEBP 캡처 이미지 Response { "assignmentId": "receipt_id", "status": "COMPLETED | REVIEW_SUBMITTED | REJECTED", "earned": 5000, "balance": 25000, "pendingApproval": false, "proofImageUrl": "/uploads/review-proofs/...", "analysis": { "status": "AUTO_APPROVE", "similarity": 0.94, "reason": "DRAFT_TEXT_MATCHED" } }

상태와 원장 처리

  • Receipt.source = CAMPAIGN_ASSIGNMENT
  • 배정 직후 Receipt.status = ASSIGNED
  • 캡처 제출 후 AI 판정이 애매하면 Receipt.status = REVIEW_SUBMITTED
  • AI 자동 승인 또는 관리자 승인 후 Receipt.status = COMPLETED
  • AI 자동 반려 또는 관리자 반려 후 Receipt.status = REJECTED
  • 캡처 URL은 reviewProofImageUrl, 생성 원고는 reviewDraftText에 저장
  • AI 판정 결과는 reviewProofAnalysisStatus, reviewProofSimilarity, reviewProofExtractedText에 저장
  • 포인트 원장 키는 campaign-complete:{assignmentId}
  • 같은 assignmentId로 재호출하면 earned = 0, alreadyCompleted = true
  • 7일 중복 제한은 배정 기록 기준으로 유지

현재 구현의 기준

포인트 적립은 Google 리뷰 API 조회가 아니라 리뷰어가 제출한 캡처 이미지의 OCR 텍스트와 생성 원고 유사도를 분석하는 방식입니다. 캡처에 더보기가 있으면 더보기 이전에 보이는 리뷰 문구만 비교하고, 더보기를 눌러 전체 본문이 보이면 전체 원고 유사도를 비교합니다. 자동 승인에는 매장명 확인, 5점 리뷰 근거, 기본 7일 이내 작성일 근거도 필요합니다.

후속 고도화 후보

후속으로 캡처 중복 이미지 탐지, Google Maps 화면 패턴 검증, 비정상 반복 신고 탐지, 관리자 일괄 승인/반려를 추가할 수 있습니다.
