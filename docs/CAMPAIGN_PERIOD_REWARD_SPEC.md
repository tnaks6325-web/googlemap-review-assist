# 캠페인 기간 표시 및 캠페인별 지급 포인트 설정 명세

## 1. 목표

- 관리자 캠페인 목록의 각 고정 높이 행에 광고 시작일과 종료일을 표시한다.
- 캠페인별 리뷰 완료 지급 포인트를 관리자가 설정할 수 있게 한다.
- 신규 및 기존 캠페인의 기본 지급 포인트를 현재 고정값 5,000P에서 500P로 변경한다.
- 리뷰어 화면의 예상 지급 포인트와 실제 승인 후 적립 포인트가 캠페인 설정값과 일치하게 한다.

## 2. 확정할 제품 동작

1. 캠페인 기간은 캠페인명/주소 아래에 `기간 YYYY.MM.DD ~ YYYY.MM.DD` 형식으로 표시한다.
2. 캠페인 행 높이와 열 너비는 현재 크기를 유지하며, 긴 텍스트는 말줄임 처리한다.
3. 상세 펼침 영역 상단에 `지급 포인트` 숫자 입력란과 저장 버튼을 둔다.
4. 목록의 기존 `지급` 열에는 누적 지급액과 함께 `건당 500P` 형식의 캠페인 설정값을 표시한다.
5. 포인트는 1P 이상 100,000P 이하의 정수만 저장할 수 있다.
6. Google Sheet 동기화는 기존 캠페인의 관리자가 설정한 포인트를 덮어쓰지 않는다. 새 캠페인은 500P로 생성한다.
7. 리뷰어가 캠페인을 배정받을 때 지급 포인트를 배정 건에 저장한다. 이후 관리자가 캠페인 포인트를 변경해도 이미 배정된 리뷰어는 배정 당시 안내된 금액을 지급받는다.
8. 기존 미완료 배정 건은 별도 저장값이 없으므로 해당 캠페인의 현재 설정값을 최초 사용 시 적용한다. 기존 완료 내역과 포인트 원장은 변경하지 않는다.

## 3. 데이터 및 API

### 데이터 모델

- `Campaign.rewardPoints Int @default(500)` 추가
- `Receipt.rewardPoints Int?` 추가
  - 신규 배정 시 캠페인의 `rewardPoints`를 복사한다.
  - 과거 배정 데이터는 `null`일 수 있으며 승인 시 캠페인 설정값, 없으면 500P를 사용한다.
- SQLite 개발 스키마와 PostgreSQL 운영 스키마를 동일하게 변경한다.

### 관리자 API

- `PATCH /api/admin/campaigns/[campaignId]`
- 요청: `{ "rewardPoints": 500 }`
- 응답: `{ "campaign": { "id": "...", "rewardPoints": 500 } }`
- 관리자 인증, same-origin 검사, 요청 제한, 정수 범위 검증을 적용한다.
- 존재하지 않는 캠페인은 404, 유효하지 않은 입력은 400으로 반환한다.

## 4. 변경 범위

- Prisma 캠페인/배정 스키마
- 관리자 캠페인 조회 타입 및 목록 UI
- 캠페인 포인트 수정 API
- 공개/리뷰어 캠페인 조회
- 리뷰어 배정 생성
- 리뷰 승인 시 포인트 거래, 지갑, 알림
- 리뷰어 홈 참여 내역 및 관리자 검수 대기 목록
- Google Sheet 캠페인 생성 기본값
- 관련 통합/도메인/UI 회귀 테스트

## 5. 제외 범위

- 시트에 지급 포인트 열을 새로 추가하거나 시트 값으로 포인트를 갱신하는 기능
- 완료된 과거 지급 거래의 재계산
- 캠페인 기간 편집 UI
- 포인트 소수점 지원

## 6. 구현 원칙

- 기존 Next.js App Router 및 Prisma 패턴을 따른다.
- 공개 인터페이스는 `rewardPoints: number`를 명시적으로 전달하고 화면에서 고정 상수를 사용하지 않는다.
- 지급 승인 트랜잭션 안에서 포인트 거래 생성과 지갑 증가를 같은 스냅샷 금액으로 처리한다.
- 관리자 저장 후 전체 새로고침 없이 해당 행의 표시값을 갱신한다.
- 기존 캠페인 행의 가로·세로 크기와 상세 펼침 레이아웃을 깨지 않는다.

## 7. 검증

- `npm test`
- `npm run lint`
- `npm run build`
- 테스트 항목:
  - 기본 캠페인은 500P로 노출된다.
  - 캠페인별 사용자 지정 포인트가 공개/리뷰어/관리자 화면에 전달된다.
  - 배정 당시 포인트가 저장되고, 캠페인 설정 변경 후에도 기존 배정 승인액은 유지된다.
  - 승인 시 거래 금액, 지갑 증가액, 알림 문구가 동일하다.
  - 잘못된 포인트 입력과 비관리자 요청이 거부된다.
  - 기간 문자열이 표시되고 캠페인 행 고정 높이가 유지된다.
  - 시트 재동기화가 수동 설정 포인트를 덮어쓰지 않는다.

## 8. 완료 기준

- 캠페인 목록 행에서 기간을 즉시 확인할 수 있다.
- 관리자가 캠페인별 지급 포인트를 저장하고 저장된 값을 다시 확인할 수 있다.
- 기본값은 모든 신규/기존 캠페인에서 500P이다.
- 리뷰어에게 표시되는 금액과 실제 지급액이 일치한다.
- 기존 완료 거래는 변하지 않고, 테스트·린트·프로덕션 빌드가 통과한다.
