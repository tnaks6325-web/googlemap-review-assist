PRD 핵심 요구사항

  • 로그인 후 첫 화면은 캠페인 목록 테이블이다.
  • 삭제 대상: 영수증 인증, 별점 체크, 좋았던 점 선택, 한마디 입력 단계.
  • 캠페인 행 클릭 시 상세 패널 또는 상세 화면으로 이동한다.
  • 원고 생성 버튼은 초안 생성과 클립보드 복사를 한 번에 수행한다.
  • Google Maps 랜딩 버튼은 저장된 정확한 캠페인 Google Maps URL을 연다.
  • 정산/운영 추적을 위해 원고 생성, 지도 열기, 등록 완료 신고 상태를 분리 기록한다.

API / 데이터 노트

GET /api/reviewer/campaigns?available=true GET /api/reviewer/campaigns/{campaignId} POST /api/reviewer/campaigns/{campaignId}/drafts POST /api/reviewer/campaigns/{campaignId}/events { type: "DRAFT_COPIED" | "MAP_OPENED" | "COMPLETION_REPORTED" } PATCH /api/reviewer/participations/{id} { status }

상태 모델

  • AVAILABLE: 참여 가능
  • DRAFT_COPIED: 원고 생성 및 복사 완료
  • MAP_OPENED: Google Maps 랜딩 완료
  • REPORTED: 리뷰어가 등록 완료 신고
  • REVIEWING: 운영자 검수 중
  • SETTLED: 정산 가능 또는 정산 완료

수용 기준

  • 리뷰어가 `/r/demo` 같은 단일 캠페인 단계 화면이 아니라 목록 화면에서 시작한다.
  • 테이블에서 진행 중/참여 가능/잔여 수량/보상/지역을 한눈에 비교할 수 있다.
  • 원고 생성 성공 시 클립보드 복사 성공 메시지를 표시한다.
  • Google Maps 이동은 새 브라우저 탭 또는 현재 모바일 브라우저 랜딩으로 동작한다.
  • Google 리뷰 자동 게시, 별점 강제, 특정 긍정 문구 강제는 하지 않는다.
